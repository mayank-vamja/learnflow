# LearnFlow AI - Demo Script

## Goal

Show a full personalized learning loop in under 3 minutes.

## Flow

1. **Open app home**
   - Introduce LearnFlow AI as an AI Learning OS
   - Mention mobile-first startup-grade product experience

2. **Input topic**
   - Enter `I want to learn Kubernetes`
   - Set daily time, learning style, and target goal

3. **Roadmap reveal**
   - Highlight milestone progression (Beginner -> Advanced)
   - Emphasize personalized structure and completion estimate

4. **Adaptive tutoring moment**
   - Explain Pod vs Deployment concept shown on screen

   - Point out mode switch triggered by AI Learning Pulse(TM)

5. **Quiz and revision**
   - Click **Generate AI Quiz**
   - Show quiz score and weak area detection
   - Explain revision recommendation behavior

6. **Dashboard update**
   - Call out mastery, confidence, completion, and streak changes
   - Show adaptive state turned active

7. **Close with vision**
   - B2C + B2B use cases
   - Future voice mentor + full analytics platform
